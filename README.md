## 安裝教學

### 1. 安裝套件

```bash
npm install
```

### 2. 建立設定檔

將

```
.env.example
```

複製一份並改名為

```
.env
```

然後填入自己的：

- Discord Token
- MSU API Key
- Discord Channel ID
- Discord Guild ID

### 3. 啟動

```bash
node bot.js
```
