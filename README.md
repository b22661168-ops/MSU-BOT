# MSU-BOT

Discord Utility Bot for MapleStory N.

## 作者

爻夜夜(yaoyaya)

## 介紹

MSU-BOT 是一個為 MapleStory N Discord 社群打造的管理機器人。

目前包含：

- 玩家中心（MSUME）
- PT 系統
- Boss 抽獎
- EXP Tracker
- ARC 最佳化
- NESO 分帳
- Transfer Center
